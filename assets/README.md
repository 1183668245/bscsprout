# 币安萌芽素材说明

以下文件路径已经在页面代码中固定引用，后续请直接使用相同文件名替换，不需要修改 HTML 结构或 CSS 布局。

## 背景素材

### `bg-farm.webp`
- 推荐尺寸：`1920 × 1080` 或更大
- 使用位置：整页农场背景
- 建议内容：蓝天、白云、丘陵、草地、树木、风车、栅栏、小路、花朵、笑脸太阳等完整场景
- 建议格式：WebP，保证透明边缘和压缩质量平衡

## 品牌素材

### `logo.png`
- 推荐尺寸：`500 × 110`
- 使用位置：左上角 Logo
- 建议内容：黑色品牌字样与嫩芽元素，透明背景

### `hero-mascot.png`
- 推荐尺寸：`1400 × 1300`
- 使用位置：首页右侧主角色插画区
- 建议内容：透明背景吉祥物，角色底部留出自然落地空间

## 底部卡片素材

### `card-land.png`
- 推荐尺寸：`320 × 240`
- 使用位置：功能卡片一“拥有土地”
- 建议内容：土地、菜园、草地类立体小场景

### `card-grow.png`
- 推荐尺寸：`320 × 240`
- 使用位置：功能卡片二“种植成长”
- 建议内容：播种、发芽、成长、太阳等农业成长元素

### `card-dividend.png`
- 推荐尺寸：`320 × 240`
- 使用位置：功能卡片三“卖菜分红”
- 建议内容：蔬菜、篮子、金币、分红感元素

### `card-lucky.png`
- 推荐尺寸：`320 × 240`
- 使用位置：功能卡片四“幸运玩法”
- 建议内容：玉米、礼盒、问号、抽奖道具等轻游戏元素

## 占位素材

### `placeholder.svg`
- 推荐尺寸：矢量文件，可任意缩放
- 使用位置：所有图片加载失败时的统一占位图
- 说明：页面脚本会在图片加载失败时自动切换到该文件

## 替换建议
- 所有图片尽量保持透明背景或与页面场景色调一致，避免替换后显得突兀。
- 如果新图主体比例变化较大，优先在源素材中留出安全边距，不建议通过改 CSS 来临时迁就。
- 替换后建议优先检查 `1672 × 941` 桌面端首屏是否仍无纵向滚动条。
